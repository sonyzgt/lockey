## 🌟 Highlights & Twitter Radar Version

- **Live Narrative Radar (`/` & `/radar`)**:
  - Real-time Twitter / X sentiment detection monitoring top crypto influencers and alpha accounts.
  - Live post streaming showing user handles, verification status, follower metrics, media previews, and exact timestamps.
  - Automated narrative extraction suggesting proposed Token Names and Symbols ($TICKER) directly from tweet text.
- **1-Click Fast Launch**:
  - Instant token deployment on Robinhood Chain with 0.0005 ETH launch fee.
  - Auto-fills token image from tweet media or author avatar.
  - Formats tweet text into description with quote and creator attribution (`Inspired by @user`).
  - Auto-fills and embeds direct tweet post URLs into the official token Website link.
  - Zero 5-year lockups: pure fair launch dynamics.
- **Bonding Curve Trading**:
  - Continuous algorithmic pricing powered by constant-product reserves ($x \cdot y = k$) against native ETH.
  - 5-second 99% decaying anti-snipe tax to protect retail traders from MEV bots.
  - Automated liquidity migration to Uniswap v4 upon hitting 4.2 ETH graduation threshold.
- **Flat Yellow Design System**:
  - High-contrast dark theme with vibrant yellow accents, crisp typography, and responsive layouts.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Web3**: Viem, Wagmi v2, TanStack Query
- **Styling**: Tailwind CSS, Lucide React Icons
- **Network**: Robinhood Chain (Chain ID: 4663, Gas: Native ETH)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
